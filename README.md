# Akshay Sharma Portfolio

Editorial portfolio for **Akshay Sharma, AI Product Manager**.

The site tells a product story: thesis, craft loop, decade of shipped AI, and the 2024 IJRSI paper on AI and education equity. Links also live on [linktr.ee/sharmaakshay](https://linktr.ee/sharmaakshay).

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Publish on GitHub Pages

1. Create a public repo named `Akshay-Sharma-AI.github.io` (user site) or any repo with Pages enabled.
2. Push this folder to the `main` branch.
3. In the repo: **Settings → Pages → Deploy from a branch → `main` / root**.
4. Site URL will be `https://akshay-sharma-ai.github.io/` or `https://akshay-sharma-ai.github.io/<repo>/`.

## Update later

- Photo: replace `images/akshay.jpg`
- Experience / projects: edit `index.html`
- Colors: `--gold` in `css/style.css`
